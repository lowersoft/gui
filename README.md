<h1 align="center">Dear LowerSoft GUI</h1>
LowerSoft GUI is a cross-platform user interface foundation for Windows and Linux, built on top of Dear ImGui. Rather than maintaining a fork, it integrates with the upstream ImGui API directly, which keeps it easy to update and free of divergence from the original library.
<br><br>
It serves as the common GUI layer for LowerSoft's commercial products and is under active development.
